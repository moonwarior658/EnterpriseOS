# Цель этапа

Перенести снабжение в EnterpriseOS и построить сквозную систему:

```text
Заявки
→ обработка
→ перемещения
→ долги
→ закупки
→ поставщики
→ накладные
→ оплаты
→ приёмка
→ iiko
→ остатки
```

После завершения этапа основная работа отдела снабжения должна выполняться через EnterpriseOS.

# Эксплуатационный MVP от 26.07.2026

Это ускоренный эксплуатационный MVP, позволяющий начать перевод подразделений
на площадку до построения полноценного фундамента снабжения. Текущий
