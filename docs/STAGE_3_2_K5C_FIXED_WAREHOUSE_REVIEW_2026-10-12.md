## Реализация

В существующей карточке себестоимости ADMIN может запустить сбор кнопкой
«Собрать себестоимость из iiko». Новый POST `/products/{id}/costs/refresh`
принимает только request_id; source, UUID изделия и склад формирует backend.
Существующие execution/outbox/worker выполняют сбор. Request path не читает
iiko. Повтор request_id возвращает тот же запуск; активный сбор повторно
не создаётся, статус обновляется в UI. HTTP 202 означает приём команды.
X3 и удалённые изделия к запуску не допускаются. Права TECHNICAL_ADMIN на
запуск и PRODUCT_COST_READ/REVIEW/CONFIRM сохранены; новые роли не добавлялись.

История, ингредиенты, точная Decimal арифметика, content/method hashes,
аудит и явное подтверждение Office остаются. Новые снимки не наследуют
оценочность старых. Department не выводится из склада: ручной запуск использует
None; рецептура с обязательным department блокирует расчёт. Отдельный mapping
UI/таблица не создавались. K3, Supply, Sales, исходные рецептуры не менялись.
Схема БД не изменена, миграции не создавались/не применялись.
